# README Cover Visual Design

## Goal

Replace the current explanatory first-screen experience with a memorable editorial hero for `SCI/SSCI Research Writing Skills`, while keeping the existing workflow diagram below the hero as supporting explanation.

## Approved direction

Use the approved **Research Writing Workbench** direction: a premium scientific-editorial scene in deep navy, warm ivory, muted teal, and a restrained coral accent. The focal idea is research evidence becoming a structured manuscript without losing its scientific meaning.

## Preview deliverable

Create one landscape README-banner concept for visual approval before changing README files.

- Aspect ratio: wide GitHub hero, approximately 3:1.
- Primary subject: an editorial research-writing workbench with evidence cards, a manuscript page, subtle scientific annotations, and a protected evidence thread.
- Mood: rigorous, calm, international, contemporary, and human-crafted.
- Copy: `SCI/SSCI RESEARCH WRITING SKILLS` and `Plan. Draft. Polish. Preserve the science.`
- Avoid: literal flowcharts, dashboard UI, fake journal logos, copied book-cover artwork, decorative AI brains, robots, graduation caps, illegible microtext, and visual clutter.

## Repository rollout after approval

After the user approves the preview, create coordinated README, GitHub Social Preview, and Chinese WeChat cover assets, then place the README hero above the project title and move the Mermaid workflow below the opening value proposition.

## Copyright boundary

Do not reproduce the cover, pages, diagrams, phrase lists, or sample text from *Science Research Writing*. The visual may express the general idea of evidence-aware research writing but must remain an original project identity.

## Acceptance criteria

- The project name is readable at README display width.
- The visual communicates scholarly writing rather than generic AI automation.
- The evidence-preservation idea is visible without requiring a literal process diagram.
- The hero remains legible on desktop and mobile GitHub pages.
- No third-party logo, cover, trademark, watermark, or copied artwork appears.
