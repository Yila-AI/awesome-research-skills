# Copyable Input Examples

## Minimal request

```text
Use $science-research-writing to help me write my paper.
Here are my current materials: [attach files]
```

## Discussion from results

```text
Use $science-research-writing to draft my Discussion.

Design: cross-sectional observational study
Sample: 612 university students
Finding 1: sleep regularity was associated with GPA
(beta = 0.17, p = 0.01)
Finding 2: sleep duration was not associated with GPA
(p = 0.42)

Intended meaning: regularity may be relevant, but the design does not
support causality. Preserve the null result and do not add citations.
```

## Introduction plan

```text
Use $science-research-writing to plan my Introduction.
The study asks whether urban tree-canopy access is associated with
adolescent physical activity. Prior studies mainly used cross-sectional
exposure measures; ours is a longitudinal cohort. Do not claim that no
prior longitudinal studies exist unless my sources establish that.
```

## Full-draft audit

```text
Use $science-research-writing to audit this manuscript before revision.
Prioritize contradictions across Title, Abstract, Results, Discussion,
and Conclusion. Do not rewrite already-clear prose. List any number,
citation, causal-strength, null-result, or scope risks first.
```

## Target-journal adaptation

```text
Use $science-research-writing to learn the rhetorical structure of the
attached target-journal papers and plan my Discussion. Learn information
functions and order only. Do not copy phrases, claims, citations, or
scientific content from the target papers.
```
