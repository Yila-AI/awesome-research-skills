# Understand the Output

## Draft or diagnosis

This is the useful deliverable: manuscript text, a section-function map, or a prioritized audit. It appears first so a novice can act without reading implementation details.

## How it is organized

This short note names the information sequence, such as finding -> comparison -> interpretation -> limitation. It helps the author review structure without exposing internal routing jargon.

## Author confirmation

This contains only a scientific choice the Skill cannot make safely, such as which conflicting sample size is authoritative or whether an interpretation reflects the author's intended meaning. `None required` means no blocking ambiguity was found; it is not a guarantee that the science is correct.

## Next step

This is one highest-priority action, not a long generic checklist.

## Risk flags

Risk flags appear only when the input or requested output creates a specific risk: unsupported causality, missing evidence, conflicting values, citation uncertainty, scope inflation, confidentiality, or a section-boundary problem.

## What the audit can and cannot prove

The included scripts can compare numbers, citation markers, protected terms, and selected semantic markers. They cannot independently validate scientific truth, citation support, statistical correctness, or journal fit. The author and relevant domain experts remain responsible for the manuscript.
