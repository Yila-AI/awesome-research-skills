# Get Started in One Minute

## Install

Node.js 18 or later is required.

```bash
npx skills add Yila-AI/awesome-research-skills \
  --global \
  --agent codex \
  --skill science-research-writing \
  --yes \
  --copy
```

## Use

Attach or paste what you already have, then say:

```text
Use $science-research-writing to help me write my paper.
Here are my current materials: [attach files or paste text]
```

That is enough to begin. You do not need to choose a mode, prepare a long prompt, know the name of every manuscript section, or supply target papers.

## What happens next

The Skill reads the materials before asking questions. It identifies whether you have an idea, research materials, a partial draft, or a full draft. It then provides the safest useful next deliverable: a section map, draft, revision, or audit.

If one missing fact would force it to guess scientific content, it completes the unaffected work and asks one focused question.

## What to attach

Useful materials include a study protocol, research question, methods notes, results table, statistical output, figures, outline, draft section, full manuscript, target-journal instructions, or relevant target papers. Provide only material you are permitted to process.

## What it will not do

It will not invent data, citations, procedures, mechanisms, limitations, interpretations, or implications. It will not turn association into causation, hide null findings, or copy wording from target papers.
