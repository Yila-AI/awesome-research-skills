# Paper to Slides 能力展示

下面这些案例展示同一套 `research-presentation` 工作流如何适配不同学科和视觉系统。
每个案例选择 4 张代表页：封面、问题/机制、结果和总结。完整的高分辨率 reader 版本继续保留在产品 Showcase 中，开源仓库只保留轻量、便于审查的预览集。

## 你可以看到什么

- 叙事会随论文改变，而不是所有学科套同一套模板；
- 结论式标题、证据来源、图表和有边界的论断在不同风格中都保持可见；
- 同一工作流可以覆盖发现科学、教育、流行病学、材料科学、社会学和统计学；
- 这些是渲染预览，运行时 Skill 的可编辑输出和质检合约见 [`skills/research-presentation`](../../skills/research-presentation/SKILL.md)。

图片应与页面上的来源标记和原论文权利一起理解，不应脱离来源单独再利用。
