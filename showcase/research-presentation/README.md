# Paper to Slides showcase

These cases show the same `research-presentation` workflow across different
research domains and visual systems. Each case includes four representative
rendered pages: cover, question/mechanism, result, and synthesis. The full
reader-resolution galleries remain in the product showcase; this repository
keeps a compact, reviewable preview set.

## What to look for

- The narrative changes with the paper instead of forcing every field into one
  template.
- Takeaway titles, evidence anchors, figures, and bounded claims remain visible
  across styles.
- The same workflow supports discovery science, education, epidemiology,
  materials science, sociology, and statistics.
- The assets are rendered previews. The runtime Skill's editable-output and QA
  contract is documented in [`skills/research-presentation`](../../skills/research-presentation/SKILL.md).

The showcase images are demonstration artifacts. They should be read together
with the source attribution shown on each slide and should not be detached from
the source paper's rights.
