# Science Research Writing — Lean Distribution

This is the use-only distribution of [`science-research-writing`](https://github.com/Yila-AI/awesome-research-skills/tree/main/skills/science-research-writing). It contains the complete runtime Skill, section-specific references, reusable evidence templates, deterministic validators, and the repository license. Benchmarks, examples, corpus materials, and promotional assets remain in the full repository.

## Install

Move the extracted `science-research-writing` directory into the Skills directory used by your Agent, then invoke:

```text
$science-research-writing
```

If your Agent supports the Skills CLI, install only this Skill directly:

```bash
npx skills add Yila-AI/awesome-research-skills --global --agent codex --skill science-research-writing --yes --copy
```

## What is included

- `SKILL.md`: routing, evidence-preservation workflow, and academic safety boundaries;
- `references/`: section-specific writing and claim-strength guidance;
- `assets/`: evidence-ledger and target-journal-model templates;
- `scripts/`: deterministic draft and writing-model validators;
- `agents/openai.yaml`: Agent interface metadata;
- `LICENSE`: Apache License 2.0.

For evaluation protocols, worked examples, copyright boundaries, and citation information, see the [full repository](https://github.com/Yila-AI/awesome-research-skills).
