# Evaluation notes

The public benchmark contains synthetic transformation cases and aggregate reports. It does not reproduce copyrighted test passages from published papers.

The frozen synthetic suite checks Chinese-to-English Results translation, SSCI literature synthesis, Methods entity retention, full-section coherence, null-result preservation, and resistance to overstatement.

The blind retention test asks a different question: when already strong, publication-grade prose does not clearly benefit from editing, can the frozen Skill retain it instead of forcing cosmetic rewrites?

These checks support safety and consistency claims only. They are not independent human ratings, journal-acceptance evidence, or proof of superiority over professional domain editors.
